☁️ Cloud Sync (multi-device, auto)

Ek baar free setup karo (5 min) aur URL yahan paste karo. Uske baad kisi bhi device par product/category/size/charge/password change karo — khud-ba-khud (~1 second baad) cloud par chala jaayega, aur baaki devices har 20 second me khud check karke apne aap update ho jayenge. Kuch bhi manually dabana nahi padega.

Naye device par URL type nahi karna — is device par "📱 Show QR" dabao, naye device par "📷 Scan QR" se wahi QR scan karo, URL apne aap fill/save ho jaayega.

  1. script.google.com kholo, "New Project" banao.
  2. Neeche wala code "Copy Code" button se copy karo, aur editor me jo default code likha hai use hatakar ye paste kar do.
  3. Upar "Deploy" → "New deployment" → type "Web app" select karo.
  4. "Who has access" → "Anyone" set karo, phir "Deploy" dabao.
  5. Jo URL mile (script.google.com/macros/... wala), use upar "Sync URL" box me paste kar do — ye same URL sabhi devices me paste karna hai.
function doGet(e) {
  var props = PropertiesService.getScriptProperties();
  var data = props.getProperty('billingData');
  return ContentService.createTextOutput(data || '{}')
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var props = PropertiesService.getScriptProperties();
  props.setProperty('billingData', e.postData.contents);
  return ContentService.createTextOutput(JSON.stringify({status:'ok'}))
    .setMimeType(ContentService.MimeType.JSON);
}
